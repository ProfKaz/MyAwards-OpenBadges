# Downloads — MyAwards-OpenBadges

**New to this project?** Follow the [end-to-end AI-assisted publication walkthrough](../Guide/AI-End-to-End-Workflow.md) for the exact inputs, prompts, AI responsibilities, manual image upload handoff and Credly import steps.

This folder is intended for **portable ZIP distributions** of the project for users who do not want to fork it.

## Options

### A. Fork or clone (recommended)
Fork [ProfKaz/MyAwards-OpenBadges](https://github.com/ProfKaz/MyAwards-OpenBadges), replace all issuer and recipient data in `config.json`, remove inherited personal records (including MS-102), add your own PNGs, then enable GitHub Pages for `main /docs`. Read [Guide/README.md](../Guide/README.md) and [Prompt-to-use-with-AI.md](../Guide/Prompt-to-use-with-AI.md).

### B. Download ZIP and create a new repository
Download the ZIP from this folder once it is generated by GitHub Actions, extract it, and upload the contents into the **root** of a new public GitHub repository, preserving hidden files (including `.github/workflows`). Do not upload the ZIP as a single file and expect GitHub Pages to unpack it. Edit `config.json` before publication (or start from `config.example.json`) and remove any inherited identity, images and generated JSON that are not yours.

Set your Pages URL in `base_url`; place PNGs under `docs/assets/<slug>.png`; run `python validate_config.py` then `python build.py` or run the GitHub Actions workflow. Enable Pages: Settings → Pages → Deploy from a branch → main → /docs.

## Test challenge

The *First Challenge* artwork is a demo asset only. Its badge **cannot be verified in Credly until its original PNG, BadgeClass and Assertion are generated and published under the same GitHub Pages site**. Cloning a repository alone is not independently verified by the repository homepage; use actual completion evidence before awarding this badge to someone.

**Important:** These are self-issued Open Badges 2.0 records. Neither Microsoft nor GitHub automatically issues or endorses them. Do not retain the original author's identity or credentials in a redistributed copy.

## Validation checklist
- `config.json` points to your exact case-sensitive public Pages URL.
- `docs/index.html`, `docs/issuer/profile.json`, each `docs/badges/<slug>.json` and `docs/assertions/<slug>.json` resolve publicly.
- `docs/assets/<slug>-openbadges2.png` contains an uncompressed `iTXt:openbadges` block.
- `recipient` matches the verified target account and the issuer is honestly identified.
- Credential verification URLs and dates are factual.
- Platform acceptance (Credly/Sessionize) is tested separately; importing does not make the upstream issuer the Open Badge issuer.
